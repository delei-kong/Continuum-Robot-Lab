# Koopman 建模与模型强化学习中期推进计划

> 版本：V2.1
>
> 更新日期：2026-10-05
>
> 目标节点：2026 年 11 月初中期答辩

## 1. 总体目标

中期答辩前，依托现有机器人闭环实验框架，完成以下科研主线：

```text
SOFA 正向绳驱仿真
    → 动力学数据集
    → Koopman 建模
    → 基于模型的强化学习
    → 复杂轨迹闭环跟踪
```

最终形成一套可运行、可复现、可量化、可视化的实验结果，用于说明：

1. Koopman 模型能够描述绳驱连续体机器人的主要动态；
2. 学习得到的模型能够服务于强化学习策略训练；
3. 策略能够在原始 SOFA 环境中完成复杂轨迹跟踪。

中期阶段优先保证完整科研链路成立，不以达到最终论文精度或完成实机迁移为目标。

## 2. 当前基础

截至 2026-10-05，项目已经具备：

- 稳定的本地—远程实验工作流；
- 统一的 tracking Pipeline、实验入口、运行产物和评价指标；
- 直线、椭圆、圆形和圆角多边形等参考轨迹；
- inverse QP 基线和任务空间 PID 外环原型；
- batch、GUI 和批量实验能力；
- 多绳正向数据闭环已通过 batch、数据质量、确定性和 GUI 人工验收。

尚未完成的核心工作是：正式数据集、Koopman 模型、模型强化学习，以及复杂轨迹上的正向闭环验证。

阶段 C 与 PID 五轨迹的 GUI 验收均已完成。既有 Pipeline 保持冻结，后续不再继续扩展 PID 或通用实验框架。

## 3. 研究主线

### 3.1 正向动力学与数据

建立“机器人状态 + 绳索动作 → 下一状态”的正向实验闭环，并生成覆盖主要工作空间和动态行为的数据集。

现有 inverse QP 链路继续作为可达性、回归和展示基线，不作为 Koopman 的主要数据来源，避免模型混入
官方逆解器行为。

### 3.2 Koopman 动力学建模

以线性模型为基础对照，逐步完成标准 Koopman 和可学习升维 Koopman，重点评价：

- 单步预测能力；
- 多步滚动稳定性；
- 对未见轨迹和输入的泛化能力；
- 是否足以支持后续闭环控制。

物理先验作为 Koopman 模型的增强方向，但必须建立在标准模型和评价链路已经跑通的基础上。

### 3.3 基于模型的强化学习

使用 Koopman 模型承担环境转移模型，训练能够根据机器人状态和参考轨迹输出绳索动作的强化学习策略。

模型预测控制可以作为验证模型控制价值的基础对照，但不能代替模型强化学习主线。策略的最终效果必须在
原始 SOFA 正向环境中评价，不能只报告学习模型内部的结果。

### 3.4 复杂轨迹跟踪

最终选择训练阶段未直接使用的复杂三维轨迹进行闭环测试，例如八字曲线、螺旋曲线和非周期多目标轨迹。

评价同时关注跟踪精度、稳定性、动作平滑性、安全约束和实时性，并保留 inverse QP 作为参考上界。

## 4. 阶段目标

| 阶段 | 目标 | 阶段门禁 |
|---|---|---|
| M0 既有阶段收口（已完成） | 阶段 C 和 PID 五轨迹 GUI 验收 | 用户确认人工验收通过 |
| M1 正向数据闭环（已完成） | 建立多绳正向控制、状态记录和数据生成能力 | 自动验证和 GUI 运动验收通过 |
| M2 正式数据集与 Koopman 建模 | 完成数据集质量审计，以及基线与 Koopman 的单步、多步评价 | 训练/验证/测试集隔离，Koopman 在独立测试集上稳定并优于基础对照 |
| M3 模型强化学习 | 利用 Koopman 模型训练轨迹跟踪策略 | 策略在原始 SOFA 中稳定运行并改善跟踪效果 |
| M4 复杂轨迹验证 | 完成未见复杂轨迹、多次重复和对比实验 | 自动指标与人工可视化验收通过 |
| M5 中期交付 | 冻结代码、配置、结果、图表和演示材料 | 核心实验可复跑，演示与备用材料齐备 |

预期节奏：10 月上旬完成正向数据闭环，10 月中旬完成 Koopman 建模，10 月下旬完成模型强化学习和复杂
轨迹验证，10 月底至 11 月初冻结答辩材料。

## 5. 中期验收目标

中期阶段完成需要同时满足：

1. 正向多绳环境和数据集可重复生成；
2. Koopman 模型完成独立测试集上的单步与多步评价；
3. 强化学习训练过程实际使用 Koopman 模型；
4. 策略回到原始 SOFA 环境完成闭环控制；
5. 至少完成三类复杂轨迹的对比实验；
6. 关键机器人运动和控制效果通过用户人工可视化验收；
7. 实验配置、模型、指标、图表和演示流程能够复现。

## 6. 范围与优先级

### 必须完成

- 正向绳驱数据闭环；
- Koopman 动力学建模；
- 基于 Koopman 的模型强化学习；
- 原始 SOFA 中的复杂轨迹跟踪；
- 完整评价和可视化演示。

### 可根据进度缩减

- Koopman 模型变体数量；
- 物理先验和消融实验数量；
- 模型自由强化学习对照；
- 超参数搜索规模；
- 复杂轨迹的数量和难度。

### 中期阶段不纳入主线

- 实机实验和 sim-to-real；
- 重新设计机器人几何；
- 大规模模型自由强化学习；
- 复杂 PINN 或视觉感知；
- 继续扩张通用实验框架。

## 7. 推进原则

- 先建立可信的正向数据，再训练动力学模型；
- 先验证 Koopman 多步预测，再开展模型强化学习；
- 训练、验证和最终测试严格隔离；
- 所有控制结论以原始 SOFA 正向环境为准；
- 未通过阶段门禁时，不用后续算法调参掩盖前序问题；
- 时间不足时优先减少变体和消融，不删除独立测试、闭环验证和人工可视化验收。

## 8. 下一阶段

当前正式进入 M2：先生成并审计训练、验证、测试隔离的正式数据集，再进行 Koopman 建模与预测评价。
