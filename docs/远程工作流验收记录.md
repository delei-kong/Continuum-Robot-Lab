### 2.2 已验证链路

```text
本地语法检查
→ 专用密钥免密连接
→ SCP 上传与 SHA-256 校验
→ tmux 后台启动
→ RTX 4090 执行 PyTorch 训练
→ 语义验收与产物哈希清单
→ SCP 回传并在本地重新校验
```

已回传 `summary.json`、`metrics.csv`、`predictions.csv`、`loss_curve.svg`、`model.pt`、`stdout.log`、`exit_code`、`COMPLETE` 和产物哈希清单。

### 2.3 实测中固化的修复

1. 非交互 SSH 不加载 Conda shell 初始化，因此环境脚本显式使用 `/opt/conda/bin/conda`。
2. 远程全局 Conda 配置包含失效镜像，因此创建环境时使用 `--override-channels`，不修改平台全局配置。

### 3.3 能力边界

该 demo 证明了：

- SOFA 二进制可无界面执行；
- SofaPython3 桥接、SoftRobots CableConstraint、网格/FEM/约束求解链路可用；

该 demo 不证明：

- 本课题的连续体机器人几何和物理参数正确；
- 控制输入、状态定义和轨迹导出已完成；
- 仿真使用了 GPU 加速；
